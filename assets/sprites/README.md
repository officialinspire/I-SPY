# I SPY reconnaissance sprite library

These authored SVG sheets are the production art source for the game's monochrome Cold War / handheld visual language.

Each sheet is 256×256 with sixteen 64×64 transparent frames. Together they provide 80 frames across environment, infrastructure, targets, intelligence clues/decoys and UI overlays.

The strict sprite palette is `#0B0B0B`, `#333333`, `#BDBDBD`, `#F6F6EE`.

See `docs/ART-DIRECTION.md` and `docs/SPRITE-SHEET.md` before editing or extending the library.
